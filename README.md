# PR Explorer Madeira — V1.7

Mobile-first PWA für private Madeira-Orientierungs- und PR-Planung.

V1.7 Schwerpunkt:
- Geory-inspirierte obere Spatial-Control-Leiste
- Satellitenansicht als Startkarte
- kompakte Toolbar bei Kartenbewegung/Zoom
- Reisezeitraum als eigenes Kalender-Werkzeug
- Karten-Einstellungen als ruhiges iOS-artiges Sheet
- Layer-Schalter für OSM/Topo/Satellit/Heatmap/Regionen/GPX/KML/Pins
- einfache Farbanpassung für GPX, KML, Heatmap und Pins
- Info-Dashboard mit Datenstatus
- Versionsnummer unten rechts

Hinweis: Koordinaten, GPX und KML bleiben aus der vorhandenen Datenbasis. Es werden keine Positionen erfunden oder angenähert.

Upload zu GitHub Pages: entpackten Inhalt hochladen, nicht die ZIP-Datei.
